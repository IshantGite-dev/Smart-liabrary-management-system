# Smart Library Management System (Unit 2)

Extends the Unit 1 library project so it manages collections of data using Python's five built-in data structures.

| Structure  | Used for |
|------------|----------|
| Dictionary | One complete book record |
| List       | The full catalogue (list of dictionaries) |
| Tuple      | ISBN, publication details, fixed configuration |
| Set        | Unique categories, authors and member IDs |
| String     | Titles, names, messages, report lines |

## Run

    python library_system.py      # demo of the integrated system
    python structure_demos.py     # every string/list/tuple/set/dict method
    python test_library.py        # 27 automated tests

Requires Python 3.8+ and no third-party packages.

## Features

Add, search (title, keyword, author), update, remove, borrow and return books; count available books; sort titles; group by genre; unique categories and authors; member registration; formatted library report.
